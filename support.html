Support

Questions, bugs or ideas? Email info@nibrally.com. A screenshot helps.

Report a problem from the game

Profile → Settings → Report a problem, or Something wrong? under any match result. Your email app opens with a short message to us and a few details about the game (version, device, language, where you are on the ladder). You can read and change everything before you press Send. Tick the box to add your save code if you want us to see your exact game.

Switch between treble, bass or both

Profile → Settings → Clef. Each clef keeps its own ladder, so you can switch back any time. Notes you already know come along.

Skip ahead if you already read notes

Profile → Take the placement test. It places you up to Duke; beat that class’s boss to make the rank official.

Change the language or note names

Profile → Settings → Language, or Note names (C D E, Do Re Mi with Si or Ti, or German names with H).

Move my progress to another device

Profile → Backup → Copy save code on the old device, then Restore on the new one and paste the code.

Turn off vibration or sound

Profile → Settings → Vibration, or the Sound slider.

Start over

Profile → Reset progress. Your settings stay.
